# Stable Projection for URP

Open **Tools > Stable Projection > Installer** to check and install the precision patch. Existing URP is required. Use the generated comparison demo and GPU validation before adopting it.

The repository README and `docs/` directory contain the installation, compatibility, technical and validation guides. Use **Restore original packages** before removing this helper or upgrading URP.

This package supports checked URP 14.0 and 17.0?17.3 source adapters. Supported version families and individually runtime-tested versions are documented separately in the repository compatibility table.
